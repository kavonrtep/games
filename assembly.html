Repeats: why k matters

A repeat is a stretch that occurs more than once in the genome. If a (k−1)-mer lies entirely inside the repeat, all copies produce the same node: the graph cannot tell the copies apart, the path branches, and the assembly stops at every branch. Drag k in the side panel and watch the red nodes.

Number of contigs for every k

Green points: the whole genome in one contig. Red: collapsed repeat. The green band starts at k = R + 2: a (k−1)-mer must be longer than the repeat to reach into the unique sequence next to it.

The trade-off. Small k: short (k−1)-mers are shared by repeat copies – and, if very short, by chance – so the graph tangles. Large k: resolves longer repeats, but every k-mer of the genome must lie inside some read; a read of length L holds only L − k + 1 k-mers, so large k needs long reads and deep coverage. Repeats longer than the reads cannot be resolved by any k – this is what long reads (PacBio, Nanopore) and paired-end or Hi-C links are for. Real assemblers (SPAdes, MEGAHIT) therefore build graphs for several k and combine them.

Sequencing errors: tips and bubbles

A single wrong base changes every k-mer that covers it – up to k wrong k-mers, each seen only once or twice. In the graph they form thin detours: a tip (dead end) when the error is near the end of a read, a bubble (a parallel arm that rejoins the true path) when it is in the middle. True k-mers are seen many times, error k-mers rarely – so a coverage threshold separates them.

How often was each k-mer seen? (k-mer count histogram)

Red: k-mers created by errors; green: true k-mers of the genome. Hover a bar for the numbers. A good threshold lies in the valley between the two groups.

In real assemblers error correction comes first (k-mers seen once are almost always errors – the same histogram is used to estimate genome size and heterozygosity, e.g. with Jellyfish and GenomeScope), then tips are clipped and bubbles popped in the graph. The price of a high threshold: true k-mers in thinly covered regions are removed as well, and the assembly breaks there. Deeper sequencing separates the two peaks.

Every question is generated with fresh sequences and checked with the same engine that builds the graphs. Wrong twice → the answer and an explanation.

  • branch point from a chance repeat (small k)

Contig bars: blue = placed once in the genome, orange = a repeat contig (fits several places), pink = made of error k-mers, red = misjoined (joins two distant parts of the genome).
