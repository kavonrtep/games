3 · E-value and the size of the database

A query with a (CA)12 microsatellite searched with and without DUST-style masking.

5 · BLAST versus Smith–Waterman

For every database sequence: the true best local alignment score (full dynamic programming) next to what BLAST found, and how many matrix cells each method looked at.
